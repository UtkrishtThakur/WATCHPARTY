# Quick Start: WebRTC Video Chat Testing\n\n## Prerequisites\n- Node.js 18+ installed\n- MongoDB running locally (`mongod` command)\n- Two browser instances or two browser profiles\n- Internet connection for Ably signaling\n\n## Step-by-Step Test\n\n### 1. Start Dev Server\n```bash\ncd d:\\webdevnew\\PROJECT@2\\stream\\watchparty\nnpm run dev\n```\nWait for \"Ready in Xs\" message\n\n### 2. Create Test Accounts\n\n**Browser 1 (Alice):**\n- Open http://localhost:3000\n- Click \"Register\"\n- Email: alice@test.com\n- Password: Test123456!\n- Name: Alice\n- Submit\n- Check email for OTP (check spam folder)\n- Enter OTP code\n- Redirected to Dashboard\n\n**Browser 2 (Bob):**\n- Open http://localhost:3000 (in different browser/profile)\n- Click \"Register\"\n- Email: bob@test.com\n- Password: Test123456!\n- Name: Bob\n- Submit\n- Verify OTP\n- Redirected to Dashboard\n\n### 3. Create & Join Room\n\n**Browser 1 (Alice):**\n- Click \"Create Room\"\n- Enter room name: \"Test Party\"\n- Click \"Create\"\n- Room created → see room code\n- Click \"Start Party\"\n- Allow camera/microphone permissions\n- You should see:\n  - Your video feed in left tile\n  - \"Waiting for others...\" message\n  - PartyControls (Mic, Cam, Leave buttons)\n\n**Browser 2 (Bob):**\n- On Dashboard, click \"Join Room\"\n- Enter room code from Alice's screen\n- Click \"Join\"\n- Room joined → allow permissions\n- Click \"Start Party\"\n- You should see:\n  - Your video feed\n  - Alice's video in a tile next to yours\n  - Participant names: \"Alice\", \"Bob\"\n\n### 4. Verify Video & Audio\n\n**Alice's Screen Should Show:**\n- Alice's video (top-left)\n- Bob's video (top-right)\n- \"Connected\" status\n- 2 participants\n\n**Bob's Screen Should Show:**\n- Bob's video (top-left)\n- Alice's video (top-right)\n- \"Connected\" status\n- 2 participants\n\n**Audio/Video Verification:**\n- Speak into microphone → other person hears\n- Wave hand → other person sees movement\n- Disable camera → see video placeholder\n- Disable microphone → see muted indicator\n\n### 5. Test Movie Sync (Host Only - Alice)\n\n**Alice's Controls:**\n- \"Select Movie\" button (only visible to host)\n- Click to upload a video file (MP4, WebM, etc.)\n- File loads → preview appears\n- \"Play\" button enabled\n\n**Alice Plays Movie:**\n- Click \"Play\"\n- Movie starts on Alice's screen\n- **Bob's screen should auto-sync**:\n  - Movie appears on Bob's screen\n  - Playback position matches Alice's\n  - Audio plays from Bob's video element\n\n**Alice Pauses/Seeks:**\n- Pause video → Bob's pauses\n- Seek to 30s → Bob's jumps to 30s\n- Resume → both play together\n\n### 6. Test Controls\n\n**Microphone Button:**\n- Click to toggle\n- Red icon when muted\n- Other participants see audio disabled\n\n**Camera Button:**\n- Click to toggle\n- Red icon when disabled\n- Other participants see video placeholder\n\n**Leave Button:**\n- Click to leave room\n- Redirects to Dashboard\n- Other participants see you disconnected\n\n**End Room (Host Only):**\n- Click \"End Room\"\n- All participants disconnected\n- Room marked as inactive\n\n### 7. Browser Console Debugging\n\nOpen DevTools (F12) → Console tab → Look for:\n\n```\n🔧 ICE SERVERS: [...]\n📤 Offer created and set as local description\n📩 Offer set as remote description\n✅ Answer created and set as local description\n🧊 ICE candidate added\n📹 Received remote stream: abcd1234\n🔗 PeerConnection state: connected\n```\n\n### Expected Console Output (First 10 seconds)\n1. \"ICE SERVERS loaded\" from /api/turn\n2. \"Offer created\" from Alice\n3. \"Offer set as remote description\" at Bob\n4. \"Answer created\" at Bob\n5. \"Answer set as remote description\" at Alice\n6. Multiple \"ICE candidate added\"\n7. \"Remote stream received\" (Alice and Bob)\n8. \"PeerConnection state: connected\"\n\n## Troubleshooting\n\n### \"Failed to get local media\"\n- **Cause**: Camera/mic not permitted\n- **Fix**: Click allow in browser permission prompt, refresh page\n\n### \"WebRTC connection not establishing\"\n- **Cause**: Ably not connected\n- **Fix**: Check NEXT_PUBLIC_ABLY_KEY in .env.local\n- Check browser console for Ably errors (40070, 40300, etc.)\n\n### \"Can't see other person's video\"\n- **Cause**: SDP offer/answer not received\n- **Fix**: \n  - Both users in same room? (room code correct?)\n  - Both clicked \"Start Party\"?\n  - Check console for error messages\n  - Try refreshing and rejoining\n\n### \"Audio is playing but no video\"\n- **Cause**: Video track not added to stream\n- **Fix**: \n  - Check camera is enabled\n  - Check browser permissions\n  - Try another video source\n\n### \"Movie not syncing\"\n- **Cause**: Host file upload issue\n- **Fix**:\n  - Host is the only one who can upload\n  - Try a different file format (MP4 recommended)\n  - Check browser console for upload errors\n\n### \"Ably 40070 error in console\"\n- **Cause**: Invalid API key\n- **Fix**: Verify NEXT_PUBLIC_ABLY_KEY in .env.local\n\n### Server won't start\n- **Cause**: MongoDB not running or port conflict\n- **Fix**:\n  - Start MongoDB: `mongod`\n  - Or change MONGO_URI to different port\n  - Kill process on port 3000: `npx kill-port 3000`\n\n## Success Criteria Checklist\n\n- [ ] Dev server starts without errors\n- [ ] Can register two accounts\n- [ ] Can create and join room\n- [ ] Both see each other's video\n- [ ] Both can speak/hear each other\n- [ ] Host can upload movie\n- [ ] Movie syncs to all participants\n- [ ] Pause/play/seek syncs\n- [ ] Mic/cam buttons toggle properly\n- [ ] Leave room button works\n- [ ] Console shows connection state: \"connected\"\n\n## Performance Notes\n\n- First peer connection: ~2-5 seconds to establish\n- Subsequent peers: ~1-2 seconds (same ICE gathering)\n- Movie file size: Keep under 500MB for smooth streaming\n- Bandwidth: Recommend 2+ Mbps upload/download per connection\n- Best on LAN or high-speed internet (5G, fiber, fast WiFi)\n\n## File Modified\n\n- ✅ `app/hooks/useWebRTCConnection.js` - Fixed Ably event handling\n- ✅ `lib/peerConnectionHelpers.js` - Fixed SDP negotiation\n- ✅ Removed `app/api/signaling/route.js` - Conflicting old implementation\n- ✅ Removed `app/hooks/useDataChannel.js` - Unused code\n\n---\n\n**All systems ready for testing!** 🚀\n
